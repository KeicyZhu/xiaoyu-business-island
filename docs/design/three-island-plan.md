# 三岛连续旅程设计与实施计划

日期：2026-10-20。用户本轮明确要求取代此前“双子岛独立入口”设计。

## ADR-三岛学习与实战

问题：v0.4 的双子岛把原学习岛降为可选营地，既不符合先学后练，也缺少完整群岛。

决策：单一三岛世界入口；学习岛 11 关完成后，同时开放“跨境电商双十一实战”和“品牌出海实战”，各 8 阶段。两条实战相互独立，不要求先完成其中一条。跑酷仍可跳过，不作为解锁条件。

保留两个已有 localStorage key 和原事件回放版本。旧实战记录、草稿、档案和导出可保留；学习未完成时不能继续写入实战，补完学习即恢复。读取旧实战存档不要求历史事件具有新增前置条件，实时操作经过新的旅程门控。此为本地学习进度规则，不是服务器鉴权。

画面：共用一个 WebGL 海面，三种独立地形。学习岛借鉴巴厘本岛的梯田、庙宇和宽阔海湾；电商实战借鉴佩尼达狭长石灰岩半岛和码头；品牌实战为火山环湖、市集港湾。统一圆润岸线、柔光、饱满植被、砂岩及蓝绿透明浅水。参考奥比岛的连续岸线、分区地标，奥拉星的区域主题差异；原创代码模型，不复制其资产。
