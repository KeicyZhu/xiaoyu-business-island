# 学习路线：从零基础到有依据的判断

时间按个人节奏安排，不用通关速度衡量理解。遇到新词先回概念卡；暂时不需要掌握所有统计方法。

## 第一阶段：能读懂业务目标

先完成空降海滩、市场罗盘营，阅读商业手册 01—02。最低产出是一页说明：服务谁、解决什么问题、观察什么结果、哪些指标不能变差。

自检：分别解释 CTR、CVR、ROAS 的分子与分母；用一句明确的承诺替代「产品很好」；设计一项能否定自己假设的低成本验证。

## 第二阶段：能解释获客与承接

完成搜索森林、跨境桥、创意集市、广告峡谷，阅读商业手册 03—08。最低产出是一条真实可交付的用户路径：需求 → 素材／搜索 → 页面 → 交易 → 售后。

自检：指出计费方式与优化目标的区别；把点击多、成交少的问题拆到受众、承诺、页面和事件；将本地化写成可试单的检查，而不是只看翻译。

## 第三阶段：能判断效果与经营约束

完成数据灯塔、补给港，阅读商业手册 09—12。最低产出是一张口径清楚的收益表与实验计划。

自检：同一订单不能将多平台归因转化直接相加；把广告后贡献、采购现金、库存与回款分开；说明没有对照时哪些判断仍不能成立。

## 第四阶段：能平衡平台多方目标

完成商业控制塔、治理堡垒、逃生终局，阅读商业手册 13—14。最低产出是一页综合决策：证据、瓶颈、方案、约束、护栏与停止条件。

自检：排序高不等于真实收入高；误杀和漏放需要不同代价与复核机制；不要因一个指标提高就跳过用户、商家与平台的其他影响。

## 第五阶段：按问题选进阶方法

| 面临的问题 | 进阶手册入口 | 先完成的条件 |
|---|---|---|
| 实验波动大、不知是否继续 | 4—7 | 理解随机分配、分析单位、区间与护栏 |
| 没有随机实验，只有历史数据 | 8—12 | 先写目标人群、混杂和识别假设 |
| 用户／商家之间互相影响 | 11 | 理解干扰和分配单元，检查残留影响 |
| 投放产品出现预算或结果争议 | 13—16 | 分清出价、排序、计费、预算与观察结果 |
| 想让 AI 查资料或查数据 | 17—20 | 已有清楚的数据字典、权限和验收用例 |
| 结论无法复现或修复 | 21—24 | 保存版本、输入、种子、证据和失败样例 |

复杂方法不是学习顺序越靠后就越「高级正确」。如果问题没有定义清楚，增加模型复杂度通常不会解决它。

## 三轮自测

1. 第一次独立作答，记录错误理由。
2. 对照解释后，用自己的话复述概念，并修改原来的方案。
3. 隔一段时间换数据或业务条件再判断；说明哪些前提变化会让原答案不再成立。

游戏内记录错题与重试，当前没有自动间隔调度或独立迁移评分。手册里的新练习可作自测，但也不能替代真实业务实践。
