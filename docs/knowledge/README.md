# 零基础商业化与出海知识库

这份知识库把已有资料按学习问题重新组织。先理解目标和用户，再学习获客、广告、测量、利润、履约与平台，最后进入因果推断和 AI 工具方法。

公开交付由原创教材、模拟例子、练习、地图映射与来源覆盖组成；不是原始付费资料的下载站，也不把某个平台的内部个案当作普遍规则。

## v0.5：先学习，再在两个完整项目中实战

学习岛完成11关后，同时开放[跨境电商双十一实战／品牌出海实战](../product/twin-campaigns.md)，各8阶段，合计96道单选／多选／计算／排序题，以及16份开放方案。平台主线按用户提供的JD覆盖DNC/MAC、用户分层、拉新促活留存召回、补贴、A/B、ROI和团队协同。

现实案例包括淘宝天猫历史双十一、TikTok品牌案例、DANA/Lazada、Changi Pay/Alipay+及官方退款文档。案例背景有公开出处，玩家任务数据仍明确为仿真，不能当企业内部数据。

新增GTM36个正文文件去重为18份；TikTok参考PDF去重为一份282页。两组资料的方法、表格与题型已经整合，来源的面试真实性、商业结果和时效规则不因文件标题而被认定。原先“进阶尚未做成关卡”的范围仅指其他因果／AI支线，不包括本轮已实现的双岛。

## 商业主线：14 节

1. 商业目标：用户价值、业务结果、指标和护栏。
2. 市场与 GTM：客群、价值主张、可服务范围与最小验证。
3. 本地化：语言、币种、支付、承诺与履约。
4. 搜索需求与 SEO：意图、页面承接、自然与付费流量。
5. 技术／多语言 SEO：抓取、渲染、索引、规范化与语言版本。
6. 渠道和创意：触点分工、可信卖点、变量与测试。
7. 广告运行：目标、出价、排序、计费、预算分别理解。
8. 指标与漏斗：CTR、CVR、CPC、CPM、CPA、ROAS、GMV 和退款口径。
9. 归因、数据质量与增量：事件、去重、窗口、反事实。
10. 单位经济：毛利、贡献、获客成本和可承担预算。
11. 留存、复购与 LTV：同期群、观察窗口与价值类型。
12. 现金、库存与履约：采购、回款、覆盖天数和补货。
13. 电商平台与治理：供给、商品、内容、误判、申诉与体验。
14. 综合判断：问题、证据、方案、验证和停止条件。

## 阅读和练习的约定

- 先写自己的判断，再看例子／自检要点。
- 所有金额与比率都先确认分母、窗口、币种、含税／退款和成本口径。
- 「归因到某渠道」与「该渠道带来增量」分开。
- 模型预测不等于已实现结果；公开方法不等于某家平台当前实现。
- 有利润不等于有现金，ROAS 高不等于净利润高。
- 练习答案是示例思路，多解题以证据、约束和验证方案评价。
- 现行市场准入、费率、物流、税务与隐私规则，使用前查阅对应市场的当前官方材料。
