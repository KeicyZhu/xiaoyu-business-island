# 双子岛产品设计与玩法

## 两个岗位、两条连续任务

**用户增长岛：TikTok Shop 用户增长产品经理。** 双十一作为贯穿场景，按用户提供的 JD 组织：指标字典、用户分层、DNC诊断、MAC促活留存、召回补贴、A/B与ROI、协同上线及效果迭代。平台案例不是内部真实项目复刻，不能拿天猫、Lazada或钱包网络案例拼成TikTok内部系统。

**品牌出海岛：中国蟹黄酱品牌GTM负责人。** 市场选择、STP、SKU与食品条件、定价、渠道支付、整合营销、上市WBS与履约、复购现金扩张。品牌尚未命名，项目数据为仿真；李锦记和Eatsambel提供有边界的真实类比，不是该蟹黄酱品牌真实成绩。

## 每阶段怎样玩

1. **现实案例与材料**：阅读公开实体、市场、日期、来源和不能外推的内容；随后读取独立仿真表格与本阶段概念。
2. **业务决策**：比较3个方案的投入、准备和体验取舍。选择及后果写入后续交接，预算不会每关重置。
3. **实战题**：每关6题，包含情境单选、多选、数值计算和行动排序。解释对应材料与算式；可以查看反馈后纠错。
4. **阶段交付**：写至少40字方案，自查至少3项，提交后领取阶段成果，解锁下一阶段。

两条线各8阶段、48题，合计16阶段96题。48张概念解释卡与16份开放交付物独立于原基础营地的33概念、44基础选择题。旧基础营地的11案例也改成了真实平台／海外钱包背景与原创仿真任务。

## 指标字典

用户未提供内部定义并授权自定，游戏采用训练口径：DNC=指定时区内当日首次有效支付去重购买用户；MAC=自然月内至少一次有效支付去重购买用户。具体截止时间、退款和身份去重在各阶段给定。它们不是经核实的 TikTok Shop 官方内部定义。

按月去重人数不能用日活或每日买家数直接累加；首购不能用注册人数代替。增长ROI应说明增量贡献、补贴、触达与服务成本的边界，不用平台广告归因ROAS代替因果结果。

## 仿真机制与边界

初始项目预算由任务定义。每次提交按所选方案一次性变更预算、上线准备和体验信任，后两者限制在0—100；重复提交不重复授予成果。

这是一套**固定业务材料＋可累计决策账本**：前序方案、资源与交接会在下一阶段显示，并提示需要处理的风险。材料中的市场规模、订单表和支付数据不会因玩家选择自动生成新的市场预测。准备／信任是显式教学量表，没有声称来自企业模型。

开放方案只检查字数和自查步骤，不进行AI语义评分；客观题公开答案，适合自主练习而非防作弊考试。复杂判断可接受多种有证据的方案，不能把唯一渠道选择当行业标准答案。

## 存档、报告与跑酷

双岛存档键为 xiaoyu-twin-campaign-v1，版本1.0.0，与旧基础营地存档分开。导出只存合法事件，导入通过规则重放恢复，拒绝伪造完成和非法顺序。损坏原存档暂停覆盖，可先导出原始文件后确认重置。

「我的双岛任务档案」记录已完成阶段、选项、结果和文字交付，可导出。新两条主线不加入跑酷；分别录制的演示视频也只展示案例、决策、解题、交付和报告。
