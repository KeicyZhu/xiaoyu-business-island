# 三岛旅程中的两条实战任务

版本：v0.5.0。三岛门控与统一海面已实现，并通过浏览器流程验收。文件名保留 `twin-campaigns.md` 以兼容已有链接。

## 先学后练的三岛入口

首页共用一个 3D 海面展示学习海湾、佩尼达海崖和火山港湾。先完成「学习岛」11 关，随后同时开放「跨境电商双十一实战」和「品牌出海实战」，两条线独立推进，无须先完成另一条。跑酷可跳过，不作为解锁条件。

地形和模型采用原创代码，参考巴厘地理、奥比岛的岸线与地标组织、奥拉星的地区差异，统一圆润海岸、植被、柔光和浅水效果；不复制游戏资产或声称高保真还原。

## 两个岗位、两条连续任务

**跨境电商双十一实战：TikTok Shop 用户增长产品经理。** 双十一作为贯穿场景，按用户提供的 JD 组织：指标字典、用户分层、DNC诊断、MAC促活留存、召回补贴、A/B与ROI、协同上线及效果迭代。平台案例不是内部真实项目复刻，不能拿天猫、Lazada或钱包网络案例拼成TikTok内部系统。

**品牌出海实战：中国蟹黄酱品牌 GTM 负责人。** 市场选择、STP、SKU与食品条件、定价、渠道支付、整合营销、上市WBS与履约、复购现金扩张。品牌尚未命名，项目数据为仿真；李锦记和Eatsambel提供有边界的真实类比，不是该蟹黄酱品牌真实成绩。

## 每阶段怎样玩

1. **现实案例与材料**：阅读公开实体、市场、日期、来源和不能外推的内容；随后读取独立仿真表格与本阶段概念。
2. **业务决策**：比较3个方案的投入、准备和体验取舍。选择及后果写入后续交接，预算不会每关重置。
3. **实战题**：每关6题，包含情境单选、多选、数值计算和行动排序。解释对应材料与算式；可以查看反馈后纠错。
4. **阶段交付**：写至少40字方案，自查至少3项；客观题全部答对、业务策略已选且项目预算足够，才能提交并解锁该线下一阶段。

两条线各8阶段、48题，合计16阶段96题。48张概念解释卡与16份开放交付物独立于学习岛的33概念、44基础选择题。学习岛的11案例也改成了真实平台／海外钱包背景与原创仿真任务。

## 指标字典

用户未提供内部定义并授权自定，游戏采用训练口径：DNC=Asia/Jakarta 自然日内当日首次有效支付去重购买用户；MAC=该时区自然月内至少一次有效支付去重购买用户。具体截止时间、退款和身份去重在各阶段给定。它们不是经核实的 TikTok Shop 官方内部定义。

按月去重人数不能用日活或每日买家数直接累加；首购不能用注册人数代替。增长ROI应说明增量贡献、补贴、触达与服务成本的边界，不用平台广告归因ROAS代替因果结果。

## 仿真机制与边界

初始项目预算由任务定义。每次提交按所选方案一次性变更预算、上线准备和体验信任，后两者限制在0—100；重复提交不重复授予成果。

这是一套**固定业务材料＋可累计决策账本**：前序方案、资源与交接会在下一阶段显示，并提示需要处理的风险。材料中的市场规模、订单表和支付数据不会因玩家选择自动生成新的市场预测。准备／信任是显式教学量表，没有声称来自企业模型。

开放方案只检查字数和自查步骤，不进行AI语义评分；客观题公开答案，适合自主练习而非防作弊考试。复杂判断可接受多种有证据的方案，不能把唯一渠道选择当行业标准答案。

## 存档、报告与跑酷

学习岛沿用 `xiaoyu-island-save-v1`，两条实战共同沿用 `xiaoyu-twin-campaign-v1`；事件规则版本继续为 1.0.0，产品版本升级不改写旧存档键。学习存档上限 5 MiB，实战存档上限 2 MiB，分别导出和导入。

历史实战事件仍按原规则重放，不要求旧事件带有新增学习前置条件。读取旧档案与恢复写入是两件事：学习岛未完成时，可查看和导出旧实战记录，但不能继续填写、答题或提交；补完 11 关后恢复原进度。重置学习会重新锁定入口，不删除实战档案；重置实战不影响学习存档。

新增门控由 `journey.js` 从已经重放验证的学习状态派生，并在实时实战操作前检查。它是本地学习顺序规则，不是服务器鉴权或考试防作弊机制。导入仍拒绝伪造完成与非法事件顺序；损坏原实战存档暂停覆盖，可先导出原始文件再确认重置。

三岛地图的「实战任务档案与备份」保留已完成阶段、选择、资源和文字交付。学习岛仍有可选轻跑酷；两条实战没有跑酷。v0.4 的两支演示视频仅代表当时独立入口的历史流程，不作为 v0.5 解锁流程的验证证据。
