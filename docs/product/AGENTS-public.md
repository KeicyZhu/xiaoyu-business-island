# 项目协作规则

- 先阅读 README.md、docs/PRD.md 和 docs/product/architecture.md。
- 产品是面向零基础商业化与出海学习者的静态网页；默认不添加付费 API、登录或答案上传。
- src/curriculum.js 是课程数据真源；src/state.js 是学习顺序、奖励与存档验证真源。
- 修改规则或课程时同时更新测试、地图表、玩法和 PRD；区分当前实现与未来计划。
- 新版地图必须保留全部地区名称可见、手机可操作、减少动画和无 WebGL 降级。
- Three.js 资源需处理 context loss、恢复、页面隐藏和卸载；保持 vendor 原始文件与 MIT 许可。
- 来源原文、凭据、用户学习答案和未确认权利的外部资产不得进入公开仓库。
- 公开教材用原创表达与模拟例子，区分预测／观察、归因／因果、成交／利润、计费／优化，不声称内部规则或真实业绩。
- 常用命令：npm run dev、npm test、npm run build。只发布 dist 到网页分支。
- 提交前检查实际测试结果、构建、文档链接和公开文件；修复采用正常新增提交，不改写已发布历史。
